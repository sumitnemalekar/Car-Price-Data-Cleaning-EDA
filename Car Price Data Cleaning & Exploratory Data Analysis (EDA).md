# Car Price Data Cleaning and Analysis

This project is about cleaning and analysing a car price dataset. The dataset has 2500 rows and includes details like brand, model, year, engine size, fuel type, mileage, condition and price.
The main aim of this project is to understand how different features affect the price of a car.

---

## About the Dataset

* The data was taken from Kaggle.
* The dataset has 10 columns in total.

---

## What I Did in This Project

### 1. Data Cleaning

* Checked for missing values
* Checked duplicates
* Checked category values (Brand, Fuel Type, Condition, etc.)
* Verified data ranges like Year, Engine Size, Mileage and Price

### 2. Exploratory Data Analysis (EDA)

* Price distribution
* Average price by brand
* Price vs year
* Price vs mileage
* Engine size vs price
* Price difference based on fuel type
* Most expensive cars
* Most common car brands

### 3. Visualisation

I used **Matplotlib** and **Seaborn** to make:

* Histograms
* Scatter plots
* Box plots
* Bar charts

These help in understanding the trends in the data.
